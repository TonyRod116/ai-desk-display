# AI Desk Display contributor instructions

This is the sanitized public distribution of a local TokenTV-based project.
Keep runtime credentials, account data, board pairing and actual quota captures out of Git.
Use synthetic snapshots for tests and screenshots. Unknown usage stays unknown, never zero.
Preserve upstream MIT attribution and bundled font licenses.
Do not query accounts, access hardware or flash firmware for tests without authorization.
Firmware updates require the physical connection screen; never bypass that gate.
Run `python -m unittest discover -s tests` and inspect native-size renderings for visual changes.
