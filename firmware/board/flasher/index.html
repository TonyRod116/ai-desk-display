Install or update AI Desk Display

This replaces the miner software with AI Desk Display. You can reinstall the NerdMiner firmware later. Use Chrome or Edge; USB installation is not supported here in Firefox or Safari. This page and its firmware files are served from your computer, without internet access.

Before you start
  • Save your miner's Bitcoin address and Wi-Fi settings if you plan to use it again.
  • Connect the display directly by USB to this PC, avoiding an unpowered hub.
  • Close any other program using the serial port.

1. Install or update

Standard screen (ILI9341). Start here. If AI Desk Display is already installed, this updates it while keeping Wi-Fi and pairing.

This browser cannot install over USB. Open this page in Chrome or Edge. Open this page at http://127.0.0.1:8790/flasher/

Choose the display's port, usually named CH340 or CP210x, and wait for installation to finish (about 2 minutes). If no port appears, hold the display's BOOT button while connecting it.

If the screen stays blank or looks garbled after installing the standard version, try this variant for the ST7789 screen revision.

This browser cannot install over USB. Open this page in Chrome or Edge.

2. Set up Wi-Fi from your phone

  1. The display creates a Wi-Fi network named TokenTV-Display. Join it from your phone.
  2. A setup page opens. Choose your home network and enter its password. The password travels from your phone to the display; this PC never sees it.
  3. The display shows its local address, such as http://192.168.….

3. Connect your PC using the display's address

From your project directory in the terminal, use the address shown on the display:

.venv/bin/token-tv board --url http://192.168.…

The PC creates and remembers the pairing token: there is no token to type. If you reinstall or format the display, the service can pair it again.

If its address changes, .venv/bin/token-tv board --find discovers and saves it again.

To see the address again, hold the screen for 5 seconds and release. Touch gestures never erase pairing.

Update over Wi-Fi

Firmware 3 and later supports updates without USB. Hold the screen for 5 seconds and release to open the connection screen (2 seconds on firmware 9 or older). This physical action enables the update. Then run:

.venv/bin/token-tv board --update

If the picture looks wrong

Once Wi-Fi and pairing are set up, these settings can be changed without reinstalling:

  • Upside down: .venv/bin/token-tv board --rotation 3
  • Negative colours: .venv/bin/token-tv board --invert 1
  • Red and blue swapped: .venv/bin/token-tv board --swap-rb 1
  • Scrambled colours: .venv/bin/token-tv board --swap-bytes 1
  • Blank or garbled screen: try the ST7789 variant above.

Everyday controls

  • Tap: move to the next of the eight screens.
  • Hold 2 seconds and release: cycle between fixed, every 30 minutes and hourly.
  • Hold 5 seconds and release: show the connection screen and enable firmware updates.
  • Automatic changes align to the half-hour or hour. The display remembers your page and rotation mode.
  • After 3 minutes without a PC update, NO DATA replaces outdated readings.
